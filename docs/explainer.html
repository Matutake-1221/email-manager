作成しようと思った理由

状況

  • 仕事で Outlook を使ってメールを管理している
  • 受信メールは 1通ごとに専用フォルダを作成して保存するルールがある
  • フォルダ名には受信日（令和）と件名を含める必要がある

問題

  • この整理作業が毎日 3〜5通 発生していた
  • 1通ごとに「フォルダ作成 → 名前入力 → .msg 保存 → 添付保存」の 5ステップ が必要
  • そのたびに 仕事の流れが止まってしまう のがずっと気になっていた

アプリでできること

ボタン1つで取り込み

Outlook でメールを選択した状態でボタンを押すと、指定した保存先にフォルダが作成されてメールが保存される。

複数メールを一括処理

Outlook で複数のメールを選択（Ctrl+クリック）してからボタンを押すと、選択した数だけのフォルダが自動で作られる。

令和日付＋件名がフォルダ名に

受信日（令和表記）と件名を組み合わせたフォルダ名を自動生成。フォルダ内には .msg ファイルと添付ファイルがまとめて保存される。

保存先を自由に選択・記憶

「参照…」ボタンで保存先フォルダを選択できる。一度設定した保存先はアプリを閉じても記憶されるので、次回起動時に再入力は不要。

使ったツール・ライブラリ

アプリを動かすために、3つのソフトウェアをインストールした。いずれも無料・安全で使える。

Python（パイソン）

アプリ本体の開発言語
python.org からインストール

このアプリ全体を書いているプログラミング言語。無料で使えて、Windows・Mac・Linux のどこでも動く。今回のようなデスクトップツールから、データ分析・AI まで幅広く使われている言語で、世界で最も人気のあるプログラミング言語の一つ。

tkinterdnd2（ティーケーインタードロップ）

ドラッグ＆ドロップ機能の追加
py -m pip install tkinterdnd2

Python 標準の画面ライブラリ（tkinter）には、ドラッグ＆ドロップを受け取る機能がない。このライブラリを追加することで、ファイルをアプリのウィンドウにドロップして処理できるようになる。無料・オープンソース。

pywin32 / win32com（パイウィン）

Outlook との連携
py -m pip install pywin32

Python から Windows の「COM（コム）」という仕組みを使うためのライブラリ。COM とは、Windows 上のアプリ同士が情報をやり取りするための Microsoft 公式の仕組み。Outlook もこれに対応しているので、このライブラリを使うと「現在選択中のメールの件名を教えて」「添付ファイルを保存して」という操作をプログラムから直接できる。

苦戦ポイントと工夫ポイント

苦戦：win32com（pywin32）の理解

「Outlook と Python をつなぐ」という仕組みが最初はイメージしづらかった。どうやって Outlook の中を操作できるのか、職場のパソコンで本当に使えるのか、セキュリティ上の問題はないのかを一つひとつ確認する必要があった。

工夫：AI との壁打ちで理解を深めた

わからないことは AI に質問しながら進めた。「中学生でもわかるように説明してほしい」と聞いたり、「費用は？」「安全性は？」と確認したりすることで、自分が納得できるまで理解してから実装を進めることができた。

苦戦：Outlook からの直接ドラッグ＆ドロップができない

Outlook のメール一覧から直接アプリにドロップしようとしたが、うまく動かなかった。調べると Outlook が D&D 時に渡すデータが特殊な形式であることが原因だった。

工夫：「Outlook から取り込む」ボタンで解決

D&D の代替手段として、Outlook で選択中のメールを直接読み取る「Outlook から取り込む」ボタンを追加した。セキュリティ面でも安全な方法（Outlook で選択したメールだけにアクセスするため最小限の権限で動く）として採用した。
